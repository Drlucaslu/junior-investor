# Olares Junior Investor

儿童 / 青少年投资学习与模拟交易平台 · Kids investment learning & paper-trading lab (ages 10–18).
Local-first on Olares One. **Simulation only — no real brokerage, no real money.**

## What's inside

| Area | Implementation |
|---|---|
| Backend | Python 3.12 · FastAPI · SQLAlchemy 2 · Alembic · Pydantic (`apps/api`) |
| Frontend | Vite · React 18 · TypeScript · Tailwind · Recharts · i18next (`apps/web`) — zh-CN / en-US from day one |
| LLM | Any OpenAI-compatible endpoint. Parents pick it in **Settings → AI model**: the model running on Olares, or a cloud provider (OpenAI, Anthropic, Gemini, DeepSeek, OpenRouter, Qwen Cloud, custom). Keys stay on the server |
| Market / fundamentals | Yahoo Finance adapter (quotes, history, profile, statements, metrics, splits/dividends, news) + SEC EDGAR filing links. Mock adapter for offline dev |
| Search | DuckDuckGo (no key) · Tavily / Brave (API key) · Mock |
| Trading | Deterministic, ledger-first engine, Average-Cost P&L, per-profile lock; the LLM has **no** trade tool |
| Storage | SQLite on the Olares appData volume by default (PostgreSQL supported via `DATABASE_URL`) |

Deviation from the PRD's suggested stack: Vite SPA instead of Next.js, so the whole app ships as **one container** (FastAPI serves the built SPA) — simpler and lighter on Olares.

## Learning path (v0.4)
Designed around family feedback: kids should learn concepts, not chase day-to-day trading.

- **Two accounts per child.** *Learning account* — starts with $10,000; its size and allowed assets grow with the learning level; it is the only thing on the family leaderboard. *Family account* — private, funded by parents (starting cash, scheduled pocket money, one-off deposits); parents choose whether it can buy stocks & ETFs or only what the learning level unlocks. Deposits are tracked as contributions, never as profit.
- **Five levels.** Saver (cash, CDs) → Lender (+bond ETFs) → Index Investor (+equity ETFs) → Stock Picker (+stocks) → Options Apprentice (+covered calls / protective puts on shares you own; margin is a lesson only). Levels require lessons with a quick-check question and historical scenarios; a parent can start an older child at a higher level.
- **Time machine.** Five scenarios replay real monthly prices (split/dividend-adjusted, bundled in `app/data/scenarios/prices.json`) with company names hidden: 2000 dot-com, 2007 smartphones, 2008 crisis, 2020 pandemic, 2022 rate shock. The child splits $10,000, writes a reason, jumps forward three times, then sees the reveal, the market and equal-split benchmarks, max drawdown, a 2x-leverage lesson and debrief questions. Pets.com prices are approximations (delisted) and labelled as such.
- **Learning points & badges.** Points for lessons, scenarios, research and written reasons (daily caps) — nothing for trade count or returns. A coach notice appears after 5+ trades in 7 days.
- **Simulated products.** CD rates follow the 13-week T-bill yield (Yahoo `^IRX`); early withdrawal costs 1–3 months of interest (never principal). Option prices use Black-Scholes with the stock's 1-year historical volatility ±3% spread; expired options settle automatically (calls assigned / puts exercised at the strike).

## Core loop
Search → Stock page → Quick/Deep Research (source-cited, numbers rendered from data, never from the model) → Ask a Master (Buffett / Lynch / Graham / Munger AI teaching personas) → Watchlist → Thesis → Simulated trade with journal → Portfolio tracking → Research again → Reflection.

## Develop
```bash
# backend
cd apps/api && pip install -r requirements.txt pytest
MARKET_DATA_PROVIDER=mock FUNDAMENTALS_PROVIDER=mock SEARCH_PROVIDER=mock LLM_PROVIDER=mock \
  DATABASE_URL=sqlite:////tmp/dev.db uvicorn app.main:app --reload --port 8000
python -m pytest -q          # 57 tests: trading math, splits, dividends, reset, agents, learning path, CDs, options, scenarios
# frontend
cd apps/web && npm install && npm run dev      # http://localhost:5173 (proxies /api)
npm run check:i18n && npm run build            # -> apps/web/dist
```
API docs: `/api/docs`. Health: `/healthz`, `/api/v1/health?deep=true`.

## AI model settings
Settings → **AI model** (parent PIN): choose a preset, enter the endpoint URL (base URL, usually ending in `/v1`), API key and model
(“Fetch list” reads `{base_url}/models`), then **Test connection** and **Save**. The saved choice overrides the `LLM_*`
environment variables and takes effect immediately. A privacy notice reminds parents that cloud models receive the children's prompts.
Provider quirks (e.g. `max_completion_tokens`, fixed temperature) are detected and handled automatically.

## Olares Market
The Market chart is generated by `deploy/market/build_chart.py` (OlaresManifest `apiVersion: v3`, requires **Olares 1.12.6+**;
category **Lifestyle**, runs as UID 1000, `apiTimeout: 0` for streaming, en-US/zh-CN i18n). Chart 0.2.2 (legacy v1 format) covers Olares 1.12.3–1.12.5.
Upgrading from ≤0.3 runs an Alembic migration: the existing portfolio becomes the family account and a learning account is added. Icon and screenshots live in `deploy/market/assets/`; images are published to
`ghcr.io/drlucaslu/junior-investor` (GitHub Actions workflow `.github/workflows/image.yml` on `v*` tags).

## Deploy to Olares One (no registry needed)
1. Build frontend (`apps/web/dist`), then create the source bundle:
   `tar czf ji-src.tgz Dockerfile .dockerignore apps/api apps/web/dist`
2. Upload `ji-src.tgz` + `deploy/olares/build-on-olares.sh` to Olares **Files → Home/Code/junior-investor/**.
3. Control Hub → Terminal → Olares:
   ```bash
   cd /olares/rootfs/userspace/pvc-userspace-*/Home/Code/junior-investor && bash build-on-olares.sh
   ```
   (installs BuildKit once, builds the image straight into the node's containerd `k8s.io` namespace)
4. `python deploy/market/build_chart.py personal`, tar the `out/personal/juniorinvestor` folder, then Market → My Olares → **Upload custom chart** → Install.
5. Env vars (editable in Settings → Apps): `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`.

Data lives in `appData/juniorinvestor/junior_investor.db` and survives restarts/upgrades.

## Known limitations (MVP)
- US stocks/ETFs, USD, market orders, whole shares (fractional is a config flag).
- Dividends are credited on the ex-date; Yahoo dividend history is split-adjusted, so a dividend *before* a later split may be slightly under-credited.
- Keyless DuckDuckGo search can be rate-limited; set `SEARCH_PROVIDER=tavily` + key for reliability.
- Market status falls back to a clock with NYSE holidays 2025-2027.
